# [Hatarake_Saibogun / はたらけ、さいぼーぐん] 

## 🎮 Overview / 概要

[EN] An incremental roguelike action game. Direct your red blood cell through the blood vessels with simple clicks to deliver vital oxygen throughout the body!
[JP] インクリメンタル（拡大・成長）要素を取り入れたローグライクアクションゲームです。クリックで進む方向を指示しながら血管の中を駆け巡り、体中に酸素を届けましょう！（「はたらく細胞」のような世界観のゲームです）

| Category / 項目 | Details / 内容 |
| :--- | :--- |
| **Genre / ジャンル** | Incremental Roguelike / Vessel Navigation (インクリメンタルローグライク / 血管ナビゲーションアクション) |
| **Players / プレイ人数** | 1 Player (1人) |
| **Environment / 開発環境** | Unity / C# |

## 💻 System Requirements / 動作環境
- **対応OS**: Windows 11
- **Memory / 推推奨スペック**: 8GB RAM or higher (メモリ 8GB 以上)

## 🕹️ Controls / 操作方法

| Key / キー | Action (EN) | 操作内容 (JP) |
| :---: | :--- | :--- |
| **`Left Click` / 左クリック** | Set movement direction / Navigate | 進みたい方向の指定 / 進行方向の舵取り |
